# Dining integration

The adapter boundary accepts a provider's menu and nutrition responses, validates
selection echoes and provenance, and quarantines malformed or incomplete data.
Tests use only fabricated structures. No institutional source content is bundled
or redistributed by this public mirror.

The deterministic planner preserves source confidence and never treats a menu
recommendation as consumption. Live ingestion, if separately authorized, must
remain bounded and configured outside this repository.
