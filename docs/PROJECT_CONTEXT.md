# Project context

Nytr is an evidence-driven nutrition and training decision system. This public
mirror contains no owner's health history, schedule, credentials, or production
records. Local demos use synthetic fixtures and placeholder configuration.

The product keeps external evidence, deterministic calculation, optional AI
explanation, and explicit owner decisions separate. HealthKit body mass is
authoritative for weight; owner-entered profile and waist measurements are
supplementary; approved targets and goal direction are never changed silently.
