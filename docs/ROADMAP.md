# Roadmap

There is no active feature roadmap in this portfolio mirror. The core project is
engineering-complete for demonstration: deterministic nutrition and targets,
HealthKit body mass/workouts, official Hevy detail, barcode provenance, bounded
dining integration, Body & Goals setup, and optional AI explanation.

Physical-device validation, screenshots, and demo capture are deferred
presentation work. Any future capability would require a new explicit design
review; this document does not promise notifications, coaching expansion, or a
new AI phase.
