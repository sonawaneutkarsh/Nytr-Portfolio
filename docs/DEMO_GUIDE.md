# Synthetic demo guide

1. Copy `.env.example` to `.env` and fill only local development values.
2. Run the backend tests and the Swift command-line harness.
3. Use the committed synthetic dining fixtures to demonstrate parsing,
   provenance, uncertainty, and fail-closed behavior.
4. Explain that HealthKit, Hevy, and institutional dining data are integrations;
   no personal or production data is bundled here.
